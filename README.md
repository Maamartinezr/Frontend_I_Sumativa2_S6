# PixelVault Semana 6

Proyecto sumativo de Frontend I para optimizar la logica y rendimiento de una pagina web con JavaScript.

## Estructura principal

```text
index.html
assets/
  css/
    styles.css
  js/
    app.js
  img/
    imagenes del sitio y productos
  data/
    catalogo.json
    lanzamientos.json
```

## Funciones implementadas

- Bootstrap 5 para navbar, carrusel, grillas, cards, formulario y footer responsive.
- Fetch API para cargar catalogo y lanzamientos desde JSON local.
- Busqueda por formulario con evento submit.
- Carrito de compras con evento click, total y lista dinamica.
- Manejo de errores si no cargan los archivos JSON.

## Ejecucion

Abrir la carpeta con Visual Studio Code y ejecutar `Open with Live Server` sobre `index.html`.
